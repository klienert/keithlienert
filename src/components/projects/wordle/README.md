# Wordle Clone

A clone of the NY Times word game WORDLE
Unlike the NY Times version (which only offers one game a day), this can be played repeatedly and data is saved on the users local machine.

### Built With
JavaScript
React
*Compiled a list of guess words and correct words (approx. 10000 words total)

### Features
- 6 attempts to guess a 5-letter word
- color-coded tiles for feedback (same as NY Times)
- on screen keyboard
- Statistics are stored in the local storage of the user (i.e., it will change depending on your device)
