# Weather App

Basic responsive weather app that detects the users' location and displays current weather along with a two-day forcast.

### Built With
- JavaScript
- React
- Claude.ai (CSS Styling)
- WeatherAPI — current weather & forecasts
- ipapi.co — IP-based geolocation

### Features
- auto-detects user location on load
- displays temperature, percipitation and forecast
- search by US zipcode (5 digit)
- clean and responsive UI

- api.weatherapi.com/ (free weather API)
- ipapi.co/ (gets the users' IP and returns a local zipcode)
